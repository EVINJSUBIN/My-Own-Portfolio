I started coding when I was 10, probably by pretending I was a hacker and smashing keys like a tiny digital goblin. I kept going, learned a bunch of languages over the years, and now I build websites, tools, and little experiments that are a mix of useful and chaotic.

I’ve studied more than 12 languages in one way or another, which is a dramatic way of saying I was curious and a little too obsessed with making things work. HTML is not really a programming language. CSS is not really a programming language. JavaScript is the one that actually starts the party and moves the buttons around like it owns the room.
