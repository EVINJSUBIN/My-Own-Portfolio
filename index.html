story time, no cap

hey, i make web stuff.

I was in 4th grade when COVID hit, and by the time I hit 5th grade our classes had gone full online. Everyone's world got flipped, so I figured, hey, if everything's new for everyone right now, why not go learn something new too. I kept staring at the screen thinking "how does this thing even work" until it turned into an actual obsession.

I started backwards, honestly — went digging into operating systems first, before I even knew Python existed. Landed on Python as my real starting point, learned Tkinter, and made small dumb little simulations (nothing fancy, just ticking clocks and matches and stuff) to show my friends like I'd built the Matrix.

Then HTML, then React (learned it in about 10 days, no idea how), then React Native for mobile apps, then C for messing with hardware and making my own sound output like a tiny digital goblin. Go and Rust came later, mostly for AI and data work. I've studied 12+ languages this way — which is a dramatic way of saying I was curious and a little too obsessed with making things work. HTML is not really a programming language. CSS is not really a programming language. JavaScript is the one that actually starts the party and moves the buttons around like it owns the room.

All of that curiosity is currently pointed at Prex — an OS and framework I'm building from scratch, my actual dream startup. Not built for hacking, built to be open-sourced someday. Coming soon-ish.
